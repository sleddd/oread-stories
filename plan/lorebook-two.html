Persona Lorebook

Tune nine trait dials, set a passing mood, add voice tags and situational shifts. The lorebook turns the mix into prompt language and a steering file with coefficients from −2 to +2.


      

    

      

    

      
This is the full lorebook the mixer reads from. Edit any band text, pole name, tag or pattern, then apply.

      
      

    

  




Trait axes merge HEXACO, the interpersonal circumplex, adult attachment dimensions and Mehrabian’s PAD model. Contrast pairs follow the persona-vector recipe (a trait plus a natural-language description, written as opposing instructions) so each axis can also be extracted as an activation direction. Steering directions are coupled in real models, so extreme values on several axes at once can interfere.
